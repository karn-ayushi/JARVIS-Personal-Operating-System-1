# JARVIS — Personal Operating System

> **One Memory. Infinite Intelligence.**

JARVIS is an AI-powered Personal Operating System designed to act as an intelligent personal assistant. It brings conversations, memories, documents, goals, meetings, reminders, and tasks into one unified system.

---

## 🚀 Features

- 🤖 AI Companion / Chat
- 🧠 Persistent Memory
- 📄 Document Intelligence / RAG
- 🎯 Goals & Milestones
- 📅 Meeting Intelligence
- 🔔 Reminders
- ✅ Tasks & Activity Tracking
- 🗄️ PostgreSQL Database
- 🔗 Context-aware AI responses
- 🔐 User-controlled data

# 📋 Prerequisites

Before running JARVIS locally, install:

- [Node.js](https://nodejs.org/) — recommended version 22.x
- pnpm — recommended version 12.x
- Git
- PostgreSQL database / Neon account
- Google Gemini API key

Check your installed versions:

```cmd
node --version
pnpm --version
git --version
